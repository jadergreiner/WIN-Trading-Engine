# WIN-Trading-Engine

Plataforma de pesquisa e simulação de estratégias intradiárias para o mini-índice WIN (B3), com evolução planejada para execução em AWS.

> Estado: descoberta e planejamento, sem código operacional publicado neste repositório. Nenhuma ordem real ou integração com corretora está autorizada.

## Método

O planejamento seguirá o [BMad Method](https://docs.bmad-method.org/), com decisões humanas, evidências e desenvolvimento por Pull Requests. Consulte `docs/bmad/` nas branches de planejamento.

## Segurança

Este projeto é experimental e não apresenta evidência de lucratividade. Estratégias e simulações não constituem orientação individual de investimento.
